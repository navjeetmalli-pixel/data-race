Privacy Policy — Data Race Uploader

Last updated: 26 October 2026

Data Race Uploader is a personal application operated by the owner of the Data Race YouTube channel.

What it accesses

With the channel owner's permission (Google OAuth), the app uses the YouTube Data API only to upload videos, set thumbnails and add videos to playlists on the owner's own channel.

What it stores

An OAuth refresh token is stored locally in the owner's computer keychain. No other Google user data is collected, stored, sold or shared with anyone.

Other users

The app has no other users and does not collect any personal information from viewers.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The owner can revoke access at any time at myaccount.google.com/permissions.

Contact

Through the Data Race YouTube channel.
