Data Race Uploader is a personal, single-user application that publishes original animated data-visualization videos (bar-chart races and country-vs-country comparisons built from World Bank Open Data, CC BY 4.0) to the owner's own YouTube channel using YouTube API Services. It is not distributed to, or usable by, anyone other than the channel owner.

▶ Watch Data Race on YouTube

What it does

  • Uploads finished data videos to the owner's channel (videos.insert)
  • Sets each video's title, description, tags and thumbnail
  • Creates topic playlists and adds each video to them
  • Reads comments on the owner's own videos to collect viewers' requests for the next comparison (e.g. "India vs China")
  • Reads view and like counts of the owner's own videos to decide which topics to make more of
  • Reads back the owner's own channel, video and playlist details to confirm success

What it does not do

  • It never accesses any other user's YouTube data
  • It stores no personal data about viewers or subscribers (only the requested topic text, e.g. two country names)
  • It does not embed, play or modify the YouTube player
